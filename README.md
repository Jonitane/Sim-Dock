# Sim Dock

Sim Dock 是面向飞行模拟玩家的 Windows 桌面管理工具，将游戏、外部软件、模组、超级手册、内置膝板和桌面/OpenXR VR 浮窗集中到一个入口。

- [下载最新版](https://github.com/Jonitane/DCSHUB/releases/latest)
- [提交问题或建议](https://github.com/Jonitane/DCSHUB/issues)

## 主要能力

- 统一管理 DCS World、Falcon BMS、DCS Launcher、头显平台、外设驱动、语音通信和自定义工具。
- 按游戏隔离本地模组仓库、部署目录、预设和应用状态。
- 导入本地手册并提供带原文引用的超级手册问答。
- 在桌面与 OpenXR VR 中使用超级手册、内置膝板、离线中文拼音、本地语音输入和窗口捕获。
- 将设置、凭据、索引与缓存保存在用户选择的安装目录中。

## 支持范围

- Windows 10/11 x64
- DCS World、DCS Launcher 与 Falcon BMS
- OpenXR VR 环境
- VoxBind、DCS-SRS、DCS EyeMouse、MOZA Cockpit、Pimax Play、AimxyZ 和自定义 Windows 软件

Sim Dock 是玩家社区独立产品，与 Eagle Dynamics 及所接入软件的厂商、作者或项目没有隶属、授权或背书关系。

## 下载与更新

公开版本仅通过本页面的 [GitHub Releases](https://github.com/Jonitane/DCSHUB/releases/latest) 提供 Windows 安装包、版本说明和 SHA-256 校验文件。

Sim Dock 可在启动时读取这里的稳定版本信息。它不会自动下载或安装；只有标记为建议更新的正式版本才会显示通知，用户可以在设置中关闭自动检查。

## 使用支持

请通过 [GitHub Issues](https://github.com/Jonitane/DCSHUB/issues) 提交问题或建议，并附上 Windows 版本、Sim Dock 版本、相关软件版本、复现步骤和已脱敏日志。
